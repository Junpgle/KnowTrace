## 📖 项目介绍

**知迹（KnowTrace）** 是一个面向大学生及自主学习者的个性化学习系统，致力于解决传统学习工具难以持续跟踪学习状态、发现知识薄弱点以及动态安排复习内容的问题。

与仅提供 AI 问答的工具不同，知迹强调**基于真实学习行为的可解释评测与个性化学习决策**：

- **学了什么？** 管理不同学科的课程、章节与知识点。
- **掌握多少？** 根据连续答题记录估计知识掌握状态。
- **接下来学什么？** 根据知识薄弱点、先修关系及学习目标推荐练习与复习内容。
- **有没有进步？** 持续记录学习轨迹，展示知识掌握程度的变化。

本项目对应《智能应用系统课程设计 2026》第 **20** 题「智能教育评测与个性化学习系统」，同时希望逐步成长为能够长期使用的个人学习平台。

> **当前状态：v0.2.1 知识点编辑与审核原型。** 已实现课程、章节、知识点基础 API，以及文本型 PDF/PPTX 上传、按页提取及低文本页面质量提示。BKT 已有独立公式和单测，但尚未接入测评流程。已实现 Ollama 本地模型驱动的分页面知识点提取、来源引文校验、待审核状态及可选 PDF 视觉辅助；v0.2.1 新增知识点编辑、重新审核和历史记录。AI 题目生成、在线测评、完整前端仍未实现。

## 🧠 核心算法设计

### 1. 知识追踪（Knowledge Tracing）

计划采用 **BKT（Bayesian Knowledge Tracing，贝叶斯知识追踪）** 对知识点掌握情况进行动态建模。

- **输入**：题目—知识点映射、作答结果及历史答题序列。
- **输出**：知识点掌握概率估计及下一题答对概率。
- **验证**：与历史正确率等简单基线方法进行比较。

掌握概率属于模型估计，不等同于对实际学习能力的绝对判断。数据不足时，应明确提示不确定性。

### 2. 自适应测试

根据知识掌握状态、题目难度与知识点覆盖情况选择后续题目，让练习更贴合当前学习阶段。初期采用可解释的选题策略，后续根据数据量再考虑模型优化。

### 3. 个性化复习推荐

综合掌握度、近期错误情况、知识点依赖关系和学习目标，确定复习优先级，并向学习者解释推荐理由。

### 4. AI 辅助学习

大语言模型用于题目解析、知识解释和辅助生成内容；**知识状态评测和个性化决策保留可独立评价的算法模块**，避免让系统退化为普通聊天机器人。

### 拟采用的技术栈

| 模块 | 候选技术 | 主要用途 |
| --- | --- | --- |
| 前端 | Vue 3、ECharts | 课程管理、在线答题、可视化报告 |
| 后端 | Python、FastAPI | API 服务、业务逻辑和数据处理 |
| 数据存储 | SQLite（初期），必要时 PostgreSQL | 课程、题库、用户及学习记录 |
| 知识追踪 | Python、BKT | 动态掌握度估计 |

## 🔄 典型学习流程

1. 新建一门课程，例如「计算机网络」。
2. 添加课程章节、知识点以及相关题目。
3. 进行在线测评，系统保存答题结果。
4. 根据答题序列更新各知识点的掌握状态。
5. 生成薄弱点分析与下一轮练习推荐。
6. 持续学习，在分析报告中查看掌握度的变化。

## 🔬 实验与评估计划

课程设计将尽量通过可复现的实验体现算法价值，而非只展示 UI 功能。

| 研究问题 | 对比方法 | 计划指标 |
| --- | --- | --- |
| 知识状态预测是否有效？ | 历史正确率基线 vs. BKT | AUC、Log Loss |
| 自适应测试能否改善选题？ | 固定顺序 vs. 动态选题 | 知识覆盖率、测试效率 |
| 个性化推荐是否合理？ | 顺序复习 vs. 薄弱点优先 | 复习覆盖率、后续练习表现 |

具体指标将根据可获取的公开数据和真实测试条件调整；不预设实验结论。

## 🚀 快速开始（后端 M1 已验证）

Python 3.11+；在仓库根目录执行：

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r backend/requirements.txt
cd backend
uvicorn knowtrace.main:app --reload
```

Windows PowerShell 使用 `.venv\Scripts\Activate.ps1` 激活环境。运行后访问 <http://127.0.0.1:8000/docs>（Swagger API 文档）和 <http://127.0.0.1:8000/health>。

通过 `POST /api/courses` 新建课程（示例：`{"title":"计算机网络"}`），然后通过 `POST /api/courses/{course_id}/documents` 上传 PDF/PPTX（最大 30 MiB），通过 `GET /api/documents/{document_id}/chunks` 查看带页码的文本片段。新增 `GET /api/documents/{document_id}/quality` 检查低文本量页面；PDF 可通过 `GET /api/documents/{document_id}/pages/{page_number}/preview` 查看原始页面图片，以人工确认图示、公式是否遗漏。还支持课程章节及知识点的增查接口。

**目前仅支持 PDF/PPTX 中可提取的文字**；扫描件、复杂图示、公式尚不能完整理解，也没有 AI 自动出题。默认数据写入启动目录下 `data/`，可设置 `KNOWTRACE_DATA_DIR`。此 API 暂无登录认证，**只能在可信本地环境使用，不要直接暴露公网**。请勿把个人课件提交到公共仓库。

python -m pip install -r backend/requirements-dev.txt
PYTHONPATH=backend pytest -q backend/tests

## 🔒 数据与使用说明

- 学习记录、错题和个人文档需要适当的隐私保护与访问控制。
- AI 生成的答案和练习题可能存在错误，应结合原始学习资料校验。
- 掌握度预测结果仅用于学习辅助，不应作为正式教育评价依据。
