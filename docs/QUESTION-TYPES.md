# KnowTrace 四种题型与简答自评

已支持 `single_choice`、`multiple_choice`、`true_false`、`short_answer`，适用于单个知识点出题和按章节知识簇批量出题。所有候选仍需通过课件来源、字段结构和知识点映射检查，并作为待审核题目入库。

## 题型与格式

| 类型 | `options` | `correct_answer` | 判分 |
| --- | --- | --- | --- |
| 单选题 | A/B/C/D 四项 | `"A"` 等单个字母 | 完全匹配 |
| 多选题 | A/B/C/D 四项 | `["A","C"]` 等排序、去重且至少两项的数组 | 完全匹配集合；不部分给分 |
| 判断题 | `{}` 或标准标签 | JSON `true` 或 `false` | 完全匹配 |
| 简答题 | `{}` | 8–2000 字的参考答案 | 先写后看参考答案，再自评或主动 AI 评阅 |

题目解析应提供能核对的关键理由；课件原文引用匹配只证明文字来源可追溯，不代表 AI 的答案必然正确。所有题型仍可先进入候选题盲测，不要求用户提前逐题剧透。

## 简答题作答顺序

1. 在「开始练习」中看到简答题文本框，输入 1–3000 字作答并提交，答案会持久化到 SQLite。
2. 正式练习提交后可以对照自己的作答、参考答案和解析；如果是候选题盲测，则必须完成**整套试卷**，才会解锁参考答案与任何评阅按钮。
3. 点击「已学会」或「还没学会」进行自评，或自愿选择默认 AI、Ollama 或 MiMo 点击「调用 AI 评阅」。云端评阅会将题干、参考答案和你的作答发送给所选服务；可能产生费用。
4. AI 的结论允许 `learned`、`not_learned`、`uncertain`，并保存文字反馈。自评和 AI 反馈均只记录为主观复习信息，不改变答案原文。

同一道题在同一场练习里只保存一份评价；若要重新评价，请开启新练习。评阅失败不保存虚假结果，也不会代替用户自主确认学习效果。

## 计分与知识追踪

- 已审核的单知识点**单选/判断**题可供现有 BKT 诊断。
- 多选题要求答案数组完整匹配，作为客观题统计正确率，但当前不更新 BKT（暂无校准后的多选猜测率和失误率）。
- 简答题提交时不自动标记正确或错误：独立保存作答和可选的自评/AI 反馈，不计入正式客观题正确率或 BKT。题目完成页明确分别展示客观题数与简答题数。
- 候选题盲测依旧不会参与正式正确率和 BKT。此设计不会对用户作出「答完多知识点题就证明所有知识点已掌握」的推断。

## 数据兼容和 API

SQLite 初始化时有事务保护的 `question_versions` 表约束升级：在保留原有版本、子表引用、索引、触发器并检查外键完整性的前提下，加入两种新题型。原有题目、关系、审核历史和学习记录无需重新生成。新增 `short_answer_evaluations` 存储主观评价，不更改历史答题事件。

继续沿用 `POST /api/knowledge-points/{id}/generate-questions`、批量题目生成接口与 `POST /api/quiz-items/{id}/answer`；新添 `POST /api/quiz-items/{id}/short-answer-review`，请求 `{"mode":"self","verdict":"learned"}`，或 `{"mode":"ai","provider":"default"}`。只有该练习题已提交且不处于未交卷盲测时才可评价。

实际使用前建议备份 `data/knowtrace.sqlite3`。虽然迁移具备回滚和回归测试，个人课程数据库仍建议保留独立备份。
