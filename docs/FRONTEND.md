# KnowTrace v0.5.1：Vue 3 学习与题库管理工作台

这是 KnowTrace 的 Vue 3 **本地学习与题库管理前端**，提供课程总览、知识点编辑与审核、Qwen 本地 AI 出题、题目修改与人工审核、普通练习、自动判分与 BKT 学习报告。

## 启动方式（macOS）

你需要 **两个终端**，都在 KnowTrace 仓库根目录开始。

### 终端 A — FastAPI 后端

~~~bash
git pull origin main
source .venv/bin/activate
cd backend
uvicorn knowtrace.main:app --reload
~~~

请根据你自己的 Python 环境调整虚拟环境激活步骤。浏览器访问 http://127.0.0.1:8000/health 验证后端正常。

如果还要使用 AI 知识点提取/出题，在启动后端之前设置：

~~~bash
export KNOWTRACE_TEXT_MODEL=qwen3.5:4b
export KNOWTRACE_VISION_MODEL=gemma4:12b
~~~

**仅仅进行在线答题不需要启动或调用 Ollama。**

### 终端 B — Vue 3 前端

第一次使用请安装 Node.js 20.19+ 或 22+（推荐 Node.js 22）。进入仓库根目录：

~~~bash
cd frontend
npm install
npm run dev
~~~

浏览器打开：

**http://127.0.0.1:5173**

Vite 在开发时自动把 /api 和 /health 转发到 http://127.0.0.1:8000，因此本地无需修改 FastAPI 的 CORS，也无需让服务暴露公网。

以后再次启动只需要在各自的终端启动后端和 npm run dev，通常无需重复 npm install。

## v0.6.0：在网页中切换本地模型与小米 MiMo

“题库管理 → 知识点审核 → 基于此知识点生成题目”新增 **出题模型** 下拉框：

- 默认模型：使用后端 KNOWTRACE_AI_PROVIDER 指定的 Ollama（默认）或 MiMo。
- 本地 Ollama：Qwen3.5 4B，保留原有离线流程。
- 小米 MiMo · Function Calling：选择后只给模型知识点概要和资料目录，由模型按需调用后端的受限检索工具读取小段证据，不会直接发送整份课件。

在后端终端先设置 MIMO_API_KEY（**只能使用按量付费 API Key，不能使用 Token Plan 套餐 Key**）。密钥不会保存在网页中。模型默认 mimo-v2.6-flash，可以在后端通过 KNOWTRACE_MIMO_MODEL=mimo-v2.6-pro 切换。

生成结果展示 MiMo 工具调用次数、读取资料片段数及 API 返回的 Token 用量，便于对比本地模型。详见 [小米 MiMo 接入指南](MIMO-API.md)。

## 新增：网页内生成、审核题目

打开左侧 **题库管理**，无需再用 Swagger 管理题目。

1. **知识点审核**：选取一条知识点，检查摘要以及原始课件文件/页码。可以修改名称、解释、难度，或直接批准、驳回知识点。
2. **生成练习题**：选取一个 *approved* 知识点，且它必须拥有课件来源。选择 1–4 道题及题型（单选/判断），点击 **AI 生成待审核题目**。
3. **题目审核**：生成成功后切换到题目审核标签，在左侧列表选题。核查题干、四个选项、正确答案、解析和来源引用。如来源属于 figure_description（模型视觉理解的结果），点击“打开 PDF 原页核对”确认，不能将 AI 描述当作原文。
4. **批准/驳回**：阅读完整题目后勾选“我已核对……”确认，再选择审核通过；不正确的题目可以驳回。
5. **修改并创建新版本**：编辑题干、选项、正确答案、难度或解析时会创建新的待审核版本，不会覆盖旧题；必须审核新版本。题库页面显示当前最新版本。
6. **开始练习**：返回左侧“开始练习”，即可选择审核通过且相关知识点已批准的题目进行测评。

**你现在的计算机网络课程有 1 道待审核题目**（之前生成的“源系统数字比特流”单选题），在左侧“题库管理 → AI 题目审核”即可查看；没有必要重新生成。请先核查题干及原始第 2 页图片，必要时修订后再批准。

如要运行 Qwen3.5 4B 出题 + Gemma 4 12B 看图，需在**启动后端前**设置：

~~~bash
export KNOWTRACE_TEXT_MODEL=qwen3.5:4b
export KNOWTRACE_VISION_MODEL=gemma4:12b
~~~

只进行题目审核与答题，无需启动 Ollama；只有请求 AI 生成内容时才需要可用的本地模型。一次生成可能需要较长时间，按钮会显示加载状态。

## 使用方法

1. 在左侧“当前课程”选择“计算机网络”。
2. 从“学习总览”查看已审核题目数、累计答题次数、正确率与知识点掌握情况。
3. 进入“开始练习”，选择题量（至少 1 道，最多 20 道；受已审核可用题目数限制），点击“开始练习”。
4. 在单选题或判断题中选择答案，点击“提交答案”；答题前不会展示标准答案。
5. 提交后显示是否正确、正确答案与解析；点击“下一题”继续。
6. 完成后进入“学习报告”，查看 BKT 掌握度估计、累计答题次数与正确率。
7. 中途刷新网页可以根据浏览器本地保存的会话 ID 读取后端已保存的测评，恢复未完成的题目。

**注意：** 测评只能使用题目的**最新已审核版本**，且题目对应的主要知识点也必须审核通过。如果还没有可用题目，先在左侧“题库管理”生成、修改并审核题目。前端显示的“已审核题目”数与可用测评题量可能存在差异，例如题目的知识点被重新编辑成待审核时。

## 开发与部署说明

前端目录：

- src/App.vue — 课程首页、页面导航、答题与学习报告
- src/components/QuestionBank.vue — 知识点审核、AI 出题、题目修订与审核
- src/api.ts — FastAPI 类型与客户端
- src/style.css — 样式与响应式布局
- vite.config.ts — 本地 API 开发代理

检查 TypeScript 并构建：

~~~bash
cd frontend
npm run build
~~~

构建结果位于 frontend/dist。若前端需要部署到不同域名，须设置 VITE_API_BASE 并正确处理后端 CORS。当前默认只面向本地开发，不应将无认证的 FastAPI API 暴露公网。

本版本**不包含**前端上传/提取课件流程、动态自适应选题、登录/权限管理或多用户数据隔离；这些仍需要后续开发。BKT 采用固定教学示例参数，掌握度概率不等同于真实能力分数。
