# BKT 诊断可信度：2026-11 修订

## 为什么一题答对就会出现 58%？

当前 `backend/knowtrace/bkt.py` 仍为 **未经用户数据拟合的教学基线**（`bkt_v1`）。常数为：

- 初始掌握 `0.2`；
- 发生学习转移 `0.1`；
- 猜对 `0.2`；
- 失误 `0.1`。

第一次答对的后验为 `0.18 / (0.18 + 0.16) = 0.5294117647`；加学习转移后 `0.5764705882`，页面四舍五入就是 **58%**。这是模型假设的数学输出，不是实测能力。判断题和四选一单选题的猜对率目前都按同一个初值处理，这不是经过实验校准的参数。

旧版首页直接平均有 BKT 记录的知识点概率，排除所有未测评知识点，所以 58% / 71% 等数值很容易被误解为整个课程掌握率。**该展示已取消。**

## 现在如何展示学习证据？

- **学习总览**：展示“已有有效 BKT 诊断记录的知识点数 / 已审核知识点数”，不再显示伪精确的“全课程掌握概率”。进度条也使用真实的观察覆盖比例，而非随机装饰高度。
- **学习报告**：每个知识点列出 BKT 更新次数、不同题目数（同一道题的新版不算另一题）、作答日期数、客观题答对数。
- **显示阈值**：不足 5 次有效更新、3 道不同题、2 个不同的 UTC 作答日期时，模型概率默认显示为“证据不足”。满足后仍只称作“重复观测 · 未校准”，不是认证后的成绩；可以手动点击“查看原始 BKT（实验）”查看原概率。
- **避免重复抬分**：同一道题（即使改了版本）在 24 小时内第二次作答会保存客观题答案和正确率，但不再产生新的 BKT 更新事件。超过该时间的间隔练习可重新提供证据。
- **保留历史**：现有 `mastery_states`、`mastery_events` 及 `bkt_v1` 参数和旧的学习记录不改写；本次不重算历史、不重置分数，也不声称新的模型概率已校准。

这里的 5 次、3 道、2 天、24 小时均为**产品上的证据门槛/防重复规则**，不是已验证的心理测量标准，也不等于 95% 置信度。对同一段材料出的相似题，仍有相关性，不能简单看作完全独立。

## 未解决的建模问题

1. 现有 `p_guess` / `p_slip` / `p_learn` / `p_initial` 都是人工初值。不同题型（尤其判断题）、难度和课程需要经过足够数据验证，不能随意替换成“看着合理”的参数。
2. 目前没有显式的长期遗忘机制；24 小时内排除同题也不足以证明一个月后仍掌握。
3. BKT 假设一个题目由单个潜在知识状态驱动。题库允许多知识点题，但这些题不用于现有 BKT 更新，避免一个正确答案被错误解释成每个关联考点都掌握。
4. 未经内容核验的 AI 题目可能给出错误答案。批量审核只是来源/结构检验，不能把它当成知识测量的金标准。
5. 主观简答和多选题虽然会保存练习记录，但目前不进入 `bkt_v1`（没有针对这些题型校准的猜测/失误参数），不能将不同题型混入统一的概率模型后仍声称精确。

## 如何开发经过检验的后续版本？

下一阶段应在不破坏现有 v1 记录的情况下，保留答题日志、题目版本、知识点映射和作答时间；在已有足够**不同题目、跨天**的真实答题序列后：

1. 对每一种课程/题型做数据覆盖及题库质量检查；
2. 采用按时间划分的训练/验证集，估计或比较 BKT 参数（必要时引入题目层难度和间隔遗忘模型）；不要在同一训练数据上宣称预测准确；
3. 评价下一题预测的对数损失（log loss）、Brier score、概率校准和跨时间稳定性，与固定基线比较；
4. 用新的 `model_key` 保存模型版本、参数、适用课程和校准报告，旧版数值不覆盖；
5. 用可解释的测评信心和数据缺口驱动复习推荐，而不是只把原始概率四舍五入成百分比。

**结论：本次修复了“观测不足仍显示课程掌握率”和“刷同一道题可持续抬高 BKT”的可解释性和数据质量问题；并没有假装固定参数 BKT 已被训练成可靠的个性化模型。**
